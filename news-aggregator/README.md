# Daily Pulse - GitHub Pages Híraggregátor

Automatikus hírolvasó és aggregátor GitHub Pages-re tervezve, GitHub Actions cron ütemezéssel.

## Kategóriák
- Technology
- Finance
- Business
- World News

## Használat
1. Másold a fájlokat egy új GitHub repository-ba.
2. A repository **Settings** > **Actions** > **General** menüpontban állítsd a **Workflow permissions**-t **Read and write permissions**-re.
3. A **Settings** > **Pages** menüpontban kapcsold be a Pages-t a `main` ágról.
4. Indítsd el kézzel az első workflow futást az **Actions** fülön, vagy várd meg a következő ütemezett futást (05:00, 13:00, 21:00 UTC).
